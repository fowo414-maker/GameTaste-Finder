Human Resource Machine

휴먼 리소스 머신

게임 소개

Human Resource Machine은 사무실 직원이 되어 컨베이어 벨트로 들어오는 숫자를 명령어 블록으로 처리하는, 실제 프로그래밍의 기본 개념을 게임으로 옮긴 퍼즐입니다. 이 게임은 단순히 목표를 따라가는 방식보다, 플레이어가 직접 상황을 읽고 자신에게 맞는 방식으로 진행할 때 재미가 커집니다. 처음에는 값을 옮기고 더하는 정도지만, 층이 올라갈수록 반복문과 조건문에 해당하는 개념을 스스로 유추해서 짜야 합니다. 같은 문제를 더 적은 명령어로, 더 빠르게 푸는 최적화 요소도 있어 한 번 클리어한 스테이지도 다시 도전하게 됩니다. 처음 시작할 때는 시스템이 낯설 수 있지만, 몇 번의 선택과 실패를 거치면 게임이 요구하는 리듬이 분명해집니다. 논리 퍼즐을 좋아한다면 Human Resource Machine은 충분히 살펴볼 만한 작품입니다.
