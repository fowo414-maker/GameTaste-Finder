Recommendation Logic

See how the recommendation score is calculated, in four steps.

🧭

Genre Analysis

Genre is a game's backbone. When the genre matches - Action RPG, Strategy, Simulation, and so on - the controls and pacing tend to feel similar too, making it the most reliable first signal for judging taste.

The odds of a miss are lowest within the same genre.

🏷

Tag Analysis

Tags are a finer net than genre. Overlapping keywords like Open World, Co-op, Roguelike, and Story lets us pick out the games closest to your actual taste, even within the same genre.

Tags catch the details genre misses.

🕹

Play Style

Whether you want to lose yourself alone or enjoy some noisy fun with friends changes how the same game feels entirely. Comparing styles like singleplayer, co-op, story-focused, or combat-focused is what really drives your satisfaction.

In the end, style is what determines satisfaction.

🧩

Why Selecting Multiple Games Helps

A single game might just reflect your mood that day. Picking several games together makes the repeating genres, tags, and moods clearer, so the recommendation is calculated more steadily and reliably.

The more you pick past 3, the more accurate the recommendation gets.

🗺

If you like open worlds

Check whether you value freely roaming the map and discovering hidden spots. If exploring itself is more fun for you than the main quest, the Open World tag is a good guide.

If exploration is the goal, check the Open World tag first.

If you like co-op games

Player count and how the co-op works matter. It helps to check whether it's simply about being online together, or a game that gets more fun the more you split roles and communicate.

How many people, and how you play together, is what shapes the fun.

📖

If you're looking for story-focused games

Check whether it has elements like dialogue, choices, character relationships, and branching endings. When you want to immerse yourself in narrative and atmosphere more than combat, games with the Story tag are a good fit.

If narrative draws you in more than combat, prioritize the Story tag.

🔥

If you like difficult games

High-difficulty games deliver a lot of satisfaction through repeated learning and boss fights. That said, they can be fatiguing, so it's worth checking playtime and save structure too.

A good tag for anyone who enjoys learning through repetition.

⏱

If you're looking for something short

Picking a game with a short playtime, or one that wraps up in single sessions, keeps the commitment low. Look at genres like Puzzle, Platformer, or Roguelike, which can feel rewarding even in short sessions.

Perfect for when you want a sense of accomplishment without the commitment.
